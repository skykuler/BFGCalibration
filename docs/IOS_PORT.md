# iOS 2.2.0 移植范围与修复

功能基准是开源安卓版 5.0.35。保留配对、读取、Profile 与受限仪表写入、备份恢复、只读扫描和诊断导出；移除实验容量写入、写探测、容量扫值及策略豁免。

## 分层

- BFGCore：加密、组帧、状态机、原版写入策略、备份、车辆身份元数据。
- iOS 适配层：CoreBluetooth、WKWebView、Keychain 与文件分享。
- BFGSimulator：仅用于测试的车辆模型，不能证明真实车辆协议与模型一致。

iOS 不提供外设 MAC；本实现以广播中的 14 位 SN 作为身份，并核对 PRE_COMM 返回身份。密码仍保存在 Keychain，UserDefaults 仅保存车辆选择和原有参数备份。旧版本已有 Keychain 账号会迁移到车辆列表。

## 本版本修复

- 页面车辆选择与原生状态接通；恢复已配对车辆、上次选择和对应备份。
- 接收端按长度缓存 BLE 通知，支持分片、合并帧和杂字节重同步。
- 配对确认验证认证标签，日志统一脱敏 PRE_COMM / SET_PWD / AUTH 认证载荷。
- 每个客户端回调携带操作代次；取消会清理旧客户端、延时核验、风险门和待处理动作。
- 成功、失败、取消都有终止页面；风险门保留同一 nonce 下的勾选状态。
- 两遍快照只有两次读数一致才标记稳定；写前快照原子保存并读回核实。
- 蓝牙发送等待使用 CoreBluetooth 就绪回调，删除 20ms 轮询；文件编码和 I/O 移到串行后台队列，快照比较改用地址索引。
- 清除数据同步清除所有本工具凭据、车辆元数据与参数备份，兼顾旧的实验容量备份槽。

普通 Profile 与仪表写入继续保留原有条件和确认流程。本应用没有新增 Android 探测功能，也没有尝试未知协议或自动改变 B30C 的参数。

## 验证边界

回归与构建覆盖结果见 Actions。CoreBluetooth 桩和 DOM 测试不能替代实际 iOS 平台、蓝牙无线链路、真机性能与 B30C 电池校准验证。没有真机测量时，不报告 CPU 百分比、内存 MB 或零泄漏结论。
